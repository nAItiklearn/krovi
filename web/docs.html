Getting started

Krovi is a single lightweight app that puts a quick-access panel one keystroke away. There's nothing to sign into and nothing to configure before it's useful.

1. Install

Grab the Windows build from GitHub Releases and run the installer. (The releases page is a placeholder until the first build ships — watch the repository to be notified.) Krovi runs as a small tray app; optionally let it start with Windows from Settings.

2. Summon the panel

Press the global hotkey — Ctrl + Alt + Space by default — from anywhere, or click the screen hot-corner you've enabled. The panel drops down wherever you are, over whatever you're doing.

3. Find your way around

The panel has three parts:

  • Left tool rail — icons down the left edge switch between tools. Krovi's signature layout; the live preview uses the same idea.
  • Header — the current tool's name, the date and clock, quick settings, and pin / close.
  • Content area — the Home overview (a grid of glanceable cards) or a focused tool view.

4. Dismiss it

Click away, press Esc, or hit the hotkey again and it's gone. Prefer it to stay? Pin it from the header to keep it open.

No account, ever. Krovi works the moment it's installed. There is nothing to register and no licence key — it's free and open source under MIT.

The tools

Every tool on the shelf, and what it does. Each works offline except where a live fetch is noted.

Home overview

The first thing you see: a grid of cards summarising the state that matters right now — focus timer, clipboard, weather, notes, screen-time and system. Glance, act, dismiss.

Clipboard history

A searchable history of recent copies — text, images and links. Filter by type, search by substring, and pin the clips you reuse so they float to the top and are never evicted. The history has a configurable cap (default 200 unpinned entries), and re-copying something already in the list promotes it rather than adding a duplicate. Images are stored as local files referenced from the database.

Paste stack

A deliberate, numbered clipboard: push snippets into nine slots (slot 1 is the top) and pop them in order. It's a LIFO workbench, kept distinct from the passive history — ideal for filling a form or templating the same values repeatedly. A Krovi original.

Timers, stopwatch & Pomodoro

Run several countdown timers at once and a stopwatch with laps. Flip the same engine into Pomodoro mode for work/break cycles with a session counter. Each timer fires a clear notification the instant it finishes. Try a working version in the live preview.

File shelf

A holding area for drag-and-drop. Pull a file in from Explorer to park it, then drag it back out into an email, a chat or another folder when you need it. Parked files keep their original name, size and added-at, and you can name separate shelves for separate tasks.

Media now-playing

Reads the Windows media session to show whatever's playing — track, artist — with play, pause, next and previous. It only reads the session and sends transport commands; it never captures audio.

Weather

Current conditions and a short local forecast from a keyless public weather API and your Windows location. Only a coarse latitude/longitude is used, there's no account, and nothing is stored in the cloud. This is one of only two outbound calls Krovi makes — see Privacy & network audit. Disable the tool to make zero.

Calendar & reminders

A simple month view with lightweight local reminders that notify you on time. Reminders live on your machine like everything else — no sync, no account.

Quick notes & to-do

Fast scratch notes that autosave as you type, and a lightweight checkable to-do list beside them. No projects, no boards — just somewhere to drop a thought or a task in two seconds.

World clocks

Several time zones at a glance, ticking live — handy when the people you work with aren't in your city. There's a working version in the live preview.

Calculator, unit & currency conversion

An expression calculator (try it in the live preview), plus fully offline unit conversion for length, weight, temperature and more. Currency conversion uses cached rates from a keyless public FX API — the second of Krovi's two outbound calls — and falls back to the cache offline.

Command palette

One search box to launch installed apps and run Krovi actions — the keyboard spine of the shelf. A Krovi original, built so power users can live in Krovi without touching the mouse.

Screen-time tracking

Samples the foreground app and rolls it up per app, per day, for an honest picture of your attention. It records process names and durations only — never window titles, never URLs — and the aggregates never leave your machine. Export or clear them whenever you like.

Settings

Rebind the global hotkey, set a hot-corner, choose start-with-Windows, pick a light or dark theme, toggle individual tools on or off, and move your data folder. Turning a tool off that makes a network call (weather, currency) removes that call entirely.

Privacy & network audit

This is the heart of Krovi's positioning: the privacy claim is checkable, not just stated. The source is public, network access is isolated behind one small module, and the security review greps the built binary to assert the list below is exhaustive — there are no hidden sockets.

Every outbound call Krovi can make

weatherkeyless public weather API · coarse lat/long only · opt-out
currencykeyless FX rates API · no personal data · cached for offline
updateGitHub releases · manual check only · never automatic
# telemetry / analytics / ads / accounts: none

That's the whole list. Two of the three — weather and currency — are tied to a feature you opened, carry no personal data, and can be disabled, which removes the call entirely. The third is a manual update check you trigger yourself; it is never automatic.

What is never sent

  • No telemetry, analytics or usage pings.
  • No advertising or third-party tracking of any kind.
  • No account, login or cloud sync — there's nothing to sign into.
  • Screen-time records process names and durations only — never window titles or URLs — and never leaves your machine.
  • Clipboard, notes, to-dos, reminders and shelf files stay in your local data folder.

Verifiable, not just promised. A full, literal audit of every call site will live in the repository as docs/SECURITY-network-audit.md once the security phase lands. Even this website keeps the promise: no analytics, no ad scripts, no CDN fonts, no external images — everything is self-hosted.

Data & storage

Everything Krovi remembers lives in one folder under your Windows profile, which you can relocate in Settings:

  • %APPDATA%\Krovi\krovi.db — structured data: clipboard entries, notes, to-dos, reminders, shelf items, screen-time aggregates and settings.
  • %APPDATA%\Krovi\blobs\ — clipboard images and copies of parked shelf files.

No data leaves the machine. Export and clear controls are provided, so you're always in charge of what's kept.

Because Krovi is local-first with no cloud copy, your data is as safe as your machine. If you move PCs, copy the Krovi folder across, or use your own backup — there's no server holding a copy for you.

Project status

Krovi is in early development, built in the open and Windows-first. Honesty is the brand, so here's where things actually stand:

  • The Rust core is implemented and unit-tested — 61 tests passing today (clipboard, paste stack, timers, Pomodoro, file shelf, notes, to-do, screen-time and local persistence).
  • The panel UI and the Windows integrations (media, weather, currency, screen-time capture) are the next phases.
  • There is no public app release yet — the releases page is a placeholder. Watch the repo to catch the first build.
  • Windows only for now; the core is kept portable for possible future platforms.

FAQ

Is Krovi really free, with no catch?

Yes. Free and open source under the MIT licence — no key, no trial clock, no paywalled “pro” tier, no upsell. Every feature is available to everyone.

How do I know the privacy claims are true?

Read the code and run it yourself. Network access lives behind one module, the full call list is above, and a literal audit (docs/SECURITY-network-audit.md) is produced in the security phase. The claim is designed to be checkable rather than taken on trust.

Does Krovi work offline?

Almost entirely. Everything is local except the live weather forecast and fresh currency rates — and currency falls back to its cache. Disable those tools and Krovi makes no outbound calls at all.

Can I change the hotkey?

Yes. The global hotkey defaults to Ctrl + Alt + Space and is rebindable in Settings, along with the hot-corner and start-with-Windows.

Will there be a macOS or Linux version?

Not today — Krovi is Windows-first. The Rust core is deliberately kept portable so other platforms are possible later, but nothing is promised.

How can I help?

Krovi is built in the open on GitHub. Issues, ideas and pull requests are welcome as the core stabilises.
