Install

Krovi is a single small Windows app. There is nothing to sign into and nothing to configure before it’s useful.

  1. Open the download page (or GitHub Releases) and pick the x64-setup.exe installer. The .msi is there for managed deployments.
  2. Optional but recommended: check the file against the SHA-256 shown next to it on GitHub.
    PowerShell
    Get-FileHash .\Krovi_*_x64-setup.exe -Algorithm SHA256
  3. Run the installer. Windows SmartScreen may say “Windows protected your PC” because Krovi isn’t code-signed yet. Choose More info → Run anyway once you’ve verified the checksum.

About WebView2. Krovi’s interface uses the Microsoft Edge WebView2 runtime, which ships with Windows 11. If it’s missing, the installer downloads it from Microsoft. That is the installer’s download, not something the Krovi app does.

Requirements: Windows 11, 64-bit. Krovi has only been tested on Windows 11; Windows 10 is untested and may or may not work. Roughly the size of a photo to download; no account, no licence key.

First run

Krovi starts as a small pill at the top centre of your primary monitor and puts an icon in the tray. Click the pill, or press Ctrl + Alt + Space from anywhere, and it springs open into the panel.

Find your way around

  • Left rail: one icon per tool. Switch tools with a click.
  • Header: the current tool, the date and time, and the close and quit controls.
  • Content: the Home overview or a focused tool.
  • Stats strip: live memory and disk usage along the bottom.

Fold it away

Press Esc, click anywhere else, press the hotkey again, or use the panel’s close button. It morphs back into the pill and stays out of the way.

How it behaves

  • The pill never blocks your clicks. The invisible area around it passes clicks through to the app underneath; only the visible pill or panel is clickable.
  • It hides during fullscreen. Games, video and presentations that cover the whole monitor hide the pill until they end (optional).
  • One instance. Launching Krovi again expands the existing panel instead of opening a second window.
  • Always reachable. The tray icon toggles the panel on left-click; its menu has Open Krovi, Show pill, Settings and Quit Krovi.

The 15 tools

Every tool works offline except where a live fetch is noted (Weather, exchange rates, and the optional ElevenLabs read-aloud). Tools marked New in v0.2 are in the next release, not in the v0.1.0 installer. Try most of them in the live demo.

Home

The overview: cards for clipboard, focus, now playing, weather, screen time and system load. Glance, act, fold it away.

Clipboard

A live, searchable history of text, links and images. Krovi notices a copy within a fraction of a second, slides it to the top and makes the pill glow. Pin the clips you reuse; filter by type; re-copying an existing item promotes it instead of creating a duplicate. History keeps up to 200 unpinned entries, and pinned items are never evicted. Copies flagged by password managers are never stored.

LiveLocal only

Paste Stack

Nine numbered slots you push to and pop from, last in, first out, with slot 1 on top. Pushing past nine drops the oldest. It’s deliberately separate from the passive clipboard history: you decide what goes in.

9 slotsLocal only

Timers

Several countdown timers at once plus a lap stopwatch. A notification fires the moment a timer finishes, even if the panel is folded away. You can also start one by voice.

ConcurrentNotifies

Pomodoro

The timer engine in focus mode: work and break cycles with a session counter. Start it from the tool or say “start pomodoro”.

Work / breakSession count

File Shelf

A holding area for drag-and-drop. Pull a file in from Explorer to park it on a named shelf, then drag it out into an email, a chat or another folder. Parked files keep their name, size and the time you added them.

Drag in / outNamed shelves

Quick Transfer

Send files between this PC and your phone over your own Wi-Fi. Drop a file, a QR code appears, and your phone downloads it; the same page can send a file back. The small local server exists only while a share is open, serves unguessable token links on your local network, and closes itself when the share expires or you stop it. You can add a PIN to a share, and a limit on the size of uploads. Received files land in Downloads\Krovi, renamed rather than overwriting anything. There is no cloud relay and no account. It is plain HTTP, with no TLS, so anyone who can sniff your Wi-Fi could see the link and the files: use a network you trust and stop the share when you are done. Folders can’t be shared yet (pick the files inside). New in v0.2. If the phone can’t connect, see Troubleshooting.

LAN onlyQR codeAuto-expiresOptional PIN

Media

Shows whatever Windows reports as playing (Spotify, your browser, any app that registers with the system media controls): title, artist, album, artwork and a live progress bar, with play/pause, next and previous. It reads the media session and sends transport commands only; it never captures audio.

LiveWindows media session

Calendar

A month view with reminders and a bundled, offline holiday dataset. A timed entry is a real reminder. At its time, Krovi raises a Windows notification and plays the system reminder sound, whether Krovi is a pill, an open panel or hidden. Snooze it 5 or 10 minutes, dismiss it, or click it to open the Calendar. If Krovi was closed at the time, the reminder fires once on the next start, marked as missed (more than a day overdue is only marked, and four or more at once share one summary notification). Each fire is saved before the notification is shown, so a reminder never rings twice. You can also set one by voice, and Krovi reads back the exact date and time it understood. Do Not Disturb: when Windows Do Not Disturb or alarms-only is on, Windows files the notification quietly in the notification centre with no banner and no sound, Krovi skips its own sound, and the Calendar shows a one-line warning; the in-app banner still appears. Banners last about five seconds, and the Snooze and Dismiss buttons on the notification work only while the banner is on screen, so the Calendar always offers Snooze too. Reminders are new in v0.2. India covers gazetted holidays, restricted holidays and observances (Department of Personnel and Training); the US covers federal holidays (OPM); Great Britain covers England and Wales, Scotland and Northern Ireland bank holidays (GOV.UK), for 2025 to 2027. Each year’s dates carry a documented source, and nothing is fetched from the network. The holiday data is new in v0.2.

OfflineIN / US / GBReminders

Weather

Current conditions and a five-day forecast from the keyless Open-Meteo API. Your location is coarsened to about 0.1 degrees (roughly 11 km) before the request, and the request happens only when you open or refresh the tool. Never opening Weather means it never makes the call.

Network: api.open-meteo.comOptional

Notes

Fast scratch notes that autosave as you type. Real checklists sit inline with your text: tick-box items can be mixed with ordinary paragraphs in the same note. Press the mic to dictate instead of typing; the note appears in the list the moment dictation finishes. Checklists are new in v0.2.

AutosaveReal checklistsVoice dictationLocal only

Explain

Paste any text and get a summary (short, medium or key points), then have it read aloud. The summary is made on your PC with no network call; it is extractive, meaning it picks out the important sentences rather than writing new ones. Krovi does not generate AI explanations in this version. Read aloud uses the built-in Windows voices by default, on-device. Optionally, if you paste your own ElevenLabs key, read aloud can use ElevenLabs voices; that sends the text being read to ElevenLabs (api.elevenlabs.io), is off until you set it up, falls back to the Windows voice if it fails, and can be removed at any time. There is no relay and no shared key; your key is stored in Windows Credential Manager, never in plain text. New in v0.2.

On-device summaryWindows voices by defaultOptional ElevenLabs

World Clocks

Several time zones at a glance, ticking live. Handy when the people you work with aren’t in your city.

Offline

Convert

Unit conversion computed entirely on your device, plus currency conversion from reference exchange rates (ECB data via the keyless Frankfurter API). Rates are fetched when you refresh and cached, so conversion keeps working offline.

Units: offlineNetwork: api.frankfurter.app (optional)

Calculator

Type a whole expression and see the result as you go: parentheses, decimals and the usual operators, evaluated by a small built-in parser rather than eval.

Your top apps per day. Krovi samples the foreground application and records process names and durations only, never window titles and never URLs. The data stays in your local database and is never transmitted.

Voice

Krovi can turn your voice into a note and run a fixed list of commands. Recognition runs on your PC with Windows speech (SAPI 5): there is no cloud speech service, no audio upload and no account. Voice starts when you press the mic, so nothing listens in the background and there is no wake word. Voice is new in v0.2.

A closed command set, not open-ended chat. In command mode Krovi listens only for the phrasings listed on this page, plus three places where free speech is allowed: the body of a note, the text of a reminder, and the search term of “find”. Anything else is rejected or ignored; it is never interpreted, guessed at or sent anywhere. “Could you maybe pull up my stuff from last week” does nothing. Folders and apps are a closed set as well: only names Windows itself lists (below) are heard and acted on. The same wording works when you type it.

Two modes

  • Dictation. Press the mic in Notes and speak. Krovi turns what you said into a new note and refreshes the list.
  • Commands. Press the mic from the pill or panel and say one of the commands below. Krovi acts on it right away.

While you talk, the pill shows Listening and then Processing. If something goes wrong it shows an error instead of failing silently. Because the recogniser only matches phrases it was given, accuracy is high for the fixed parts and lower for free text (note bodies, reminder titles, search terms); it was measured with synthesised speech, and real microphones differ. A phrase heard with low confidence does nothing if it would launch an app (“I am not sure I heard that right… Say it again.”).

Notation below: {a|b} means one of, [x] optional, <n> a number from 1 to 99 (spoken as words or digits), <text> free speech.

Open a folder, or list what is in it

You sayExamples
{open|show|show me|go to|browse|take me to|bring up} [the|my] <folder> [folder]“open downloads”, “show my pictures”, “open krovi downloads”
{what’s in|what is in|what’s inside|what is inside|tell me about|list|list the contents of|show me what’s in} [the|my] <folder> [folder]“what’s in downloads”, “tell me about the desktop”

<folder> is exactly one of: Desktop, Documents, Downloads, Pictures, Music, Videos (the Windows known folders, wherever OneDrive or you moved them), Krovi downloads (Downloads\Krovi, where Quick Transfer saves), and the folders in Explorer’s Quick Access (pinned and frequent) by their Explorer names. Launch an app

You sayExamples
{open|launch|start|run|start up} [the] <app>“open notepad”, “launch spotify”, “start firefox”, “launch visual studio code”

<app> is one of the apps in your Start menu (Windows’ own app list plus Start-menu shortcuts), by the name shown there. Brand prefixes are optional (“chrome” for Google Chrome, “edge” for Microsoft Edge) and a few aliases are built in (“vs code”, “cmd”, “explorer”, “ppt”). A name that matches several apps equally launches nothing and lists the candidates. Web links, documents and uninstallers in the Start menu are not apps and are never launched.

Find a file by name

You sayExamples
{find file|find files|find the file|find me|search for|search my files for} <text>“search for tax return”, “find the file budget”, “find me boarding pass”

A bare “find …”, “look for …” or “locate …” is deliberately not in the spoken list (it made the recogniser swallow noisy audio that was really another command); typed, they work too. Find searches the Windows Search index for file names that contain your words (folders included), newest first, 20 results, shown as rows in the panel. A row opens its folder, or shows the file selected in Explorer; a found file is never run. There is no disk scan: only what Windows has indexed is searched (a freshly created file may not be indexed yet), and AppData is skipped.

Not supported (yet)

  • Open-ended natural language, questions, chit-chat, or several commands in one sentence (“open notes and start a timer”).
  • Folders and apps outside the sets above: any other path or drive, network shares, subfolders (“downloads slash invoices”), recent files, and websites or URLs. Voice never opens a web page.
  • Searching file contents, searching inside one folder only, searching by type, date or size (“pdfs from last week”), non-indexed locations, the web, email or messages.
  • Doing anything to a found file or folder by voice: open, run, copy, move, rename, delete or send.
  • Quitting or closing apps and windows, killing processes, and system actions (shut down, volume, brightness, Wi-Fi, lock).
  • Typing or dictating into other apps. Dictation only creates a Krovi note.
  • Editing, deleting, snoozing or listing reminders by voice; recurring reminders (“every Monday”); years in dates (“march 3rd 2027”); “next year”.
  • Languages other than English (US). Names that cannot be pronounced from their letters may not be heard.
  • Hands-free “always listening” or wake words: voice only listens after you start it.

Voice and the network

Voice makes zero network calls: dictation, the commands above, folder and app lookups, file search and reminders all run against your PC. The audit’s Voice v3 section shows the evidence: a source audit with no network API in the voice crate’s dependency tree, and a runtime capture of real recognised commands in which the process owned no TCP or UDP endpoint at any sample (with a positive control to show the capture would have seen one). What a launched app does afterwards is that app’s business, exactly as if you had started it from the Start menu; Krovi never launches a web address.

Windows must allow desktop apps to use the microphone (Settings → Privacy & security → Microphone). If voice isn’t available on your machine, the mic is disabled and Krovi says so.

Privacy & verification

The privacy claim is meant to be checkable, not just stated. The source is public, and a written audit traces every place the app can open a network connection.

Every outbound request Krovi can make

CallEndpointSentWhen

That is the whole list of outbound requests. There is no telemetry, analytics, crash reporting, advertising, account or automatic update. Updating Krovi means downloading a newer installer yourself. Two things are not on the list because they are not outbound requests: voice (dictation and every voice command make zero network calls) and Quick Transfer, which runs a short-lived server on your own local network only while a share is open.

What is never sent

  • Clipboard contents, notes, files, reminders and screen time. They stay on your PC.
  • Audio from voice, and what you said. Speech is recognised locally, and voice makes no network calls.
  • Text for the Explain summary. The summary is made on your PC. Only if you switch on the ElevenLabs voice is the text being read sent to ElevenLabs, and your key is kept in Windows Credential Manager, never in plain text.
  • Screen time never includes window titles or URLs, even locally.

Verify it yourself

  1. Read the audit: docs/SECURITY-network-audit.md.
  2. Search the source from the repository root:
    PowerShell / bash
    rg -n "ureq|TcpStream|UdpSocket|std::net::|fetch\(|XMLHttpRequest" src src-tauri/crates
  3. Watch the wire: run Krovi under Resource Monitor (Network tab), Wireshark or Fiddler. You should see traffic to the hosts above only when you use Weather (or search for a city), refresh rates, or have switched on the ElevenLabs voice. Voice commands should show none.

An honest caveat. The Tauri framework Krovi is built on pulls in HTTP libraries (reqwest, hyper) as transitive dependencies. Krovi’s own code doesn’t call them and no auto-updater is configured, but the strongest check is a network trace of the built binary, so please run step 3.

This website

The site makes no third-party requests: no analytics, no cookies, no CDNs, no third-party fonts or embeds (the typefaces and videos are served from this site). A strict Content-Security-Policy tells your browser to refuse anything else. The live counter in the privacy section checks this in your own browser.

Data & storage

  • Krovi keeps its data (clipboard history, notes, reminders, shelf items, screen-time totals and settings) in a local database in your Windows app-data folder, under %APPDATA%.
  • There is no cloud copy and no sync. If you move to a new PC, copy the folder across or use your own backup.
  • Clear your clipboard history from the Clipboard tool. Pinned items are kept unless you remove them.
  • Copies flagged by password managers are never stored in the first place.

Browser demo

The live demo is the real panel UI running in your browser with in-memory sample data and no backend. Clicking the pill expands it exactly as in the app. It is a preview, not the product: it doesn’t read your actual clipboard, media session or files, and it doesn’t send anything anywhere.

The demo is a separate page on purpose. The home page embeds it as /demo/?embed=1, which makes the page background transparent so it can sit on a wallpaper.

The native app

Install the Tauri prerequisites for Windows. The recommended setup, and the one the release workflow uses, is the MSVC toolchain: Visual Studio Build Tools with the “Desktop development with C++” workload, and rustup default stable-x86_64-pc-windows-msvc.

If your Rust host is x86_64-pc-windows-gnu, a 32-bit MinGW earlier on your PATH (for example C:\MinGW\bin) shadows the 64-bit compiler and the build fails with errors such as dlltool … Invalid bfd target. Install 64-bit WinLibs (winget install BrechtSanders.WinLibs.POSIX.UCRT) and put its mingw64\bin first on PATH for the build:

Build this website

The site is static HTML under web/. scripts/build-web.ps1 builds the demo into web/demo/ and checks that the site root is the marketing page, never the app bundle. Serve it with any static server, for example npx serve web.

Uninstall

  1. Quit Krovi: tray icon → Quit Krovi, or Ctrl + Q with the panel focused.
  2. Open Windows Settings → Apps → Installed apps, find Krovi, and choose Uninstall.
  3. Optional: delete your data. Krovi’s folders live under %APPDATA% and %LOCALAPPDATA%, in a folder named after the app (for example tech.krovi.app). There is nothing in the cloud to delete.

Troubleshooting

  • The hotkey does nothing. Another app may own that combination. Pick a different one in Settings; Krovi reports a conflict instead of ignoring it.
  • I can’t see the pill. Check the tray menu for Show pill, and remember it hides during fullscreen apps. Ctrl + Alt + Space or the tray icon still works.
  • Media is empty. Krovi shows what Windows reports. If your player doesn’t appear in the Windows volume and media overlay, it isn’t sharing a media session.
  • Weather won’t load. It needs a network connection and permission to use your location. Check Settings → Privacy & security → Location in Windows.
  • Voice is unavailable. Allow desktop apps to use the microphone in Windows privacy settings. On devices where local recognition isn’t available, Krovi disables the mic and says why.
  • My phone can’t open the Quick Transfer link. Check that the phone is on the same Wi-Fi as the PC. The first time Krovi listens, Windows may show an “Allow access” prompt: allow Krovi on Private networks. If no request reaches the share within about 20 seconds, Krovi says so and offers a read-only Check network that reports the address in use, whether Windows treats the network as Public or Private, and whether Krovi’s firewall rule exists. An Allow Krovi in the firewall button adds one rule (inbound, this program only, Private profile, local subnet) behind a Windows UAC prompt, only when you click it; Krovi never changes the firewall on its own. A network Windows classifies as Public is not helped by that rule: switch it to Private in Windows Settings. Quick Transfer is plain HTTP, so use a network you trust.
  • A reminder didn’t pop up or make a sound. If Windows Do Not Disturb (or alarms-only) is on, Windows files the notification quietly in the notification centre without a banner or sound, and Krovi skips its own sound; the Calendar shows a warning when it detects this. Notification banners last about five seconds. Reminders missed while Krovi was closed fire once on the next start, marked as missed.
  • SmartScreen warns about the installer. See Install. Krovi isn’t code-signed yet; verify the SHA-256 first.
