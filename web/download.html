Install in four steps

  1. Download the x64-setup.exe installer from the release page (the .msi is for managed deployments).
  2. Verify it. The hash must match the digest GitHub shows beside the file.
    PowerShell
    Get-FileHash .\Krovi_<version>_x64-setup.exe -Algorithm SHA256
  3. Run it. If SmartScreen says “Windows protected your PC”, choose More info → Run anyway. Krovi isn’t code-signed yet.
  4. Summon it with Ctrl + Alt + Space, or click the pill.
WindowsWindows 10 or 11, 64-bit. Tested on Windows 11; Windows 10 is untested.
ProcessorA 64-bit CPU. Local dictation and Talk to Agent need AVX2, found in CPUs from 2013 onward.
RuntimeMicrosoft Edge WebView2 (included with Windows 11). If it’s missing, the installer fetches it from Microsoft.

Why the SmartScreen warning? Windows is wary of installers from publishers it hasn’t seen before, and Krovi isn’t code-signed yet. That’s why we build in public and show a checksum for every file: you can confirm the file is exactly what GitHub Actions produced.
