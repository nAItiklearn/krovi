Install in four steps

  1. Download Krovi_0.3.0_x64-setup.exe from the release page (or the .msi for managed deployments).
  2. Verify the SHA-256 digest in PowerShell against the hash shown above:
    PowerShell
    Get-FileHash .\Krovi_0.3.0_x64-setup.exe -Algorithm SHA256
  3. Run the installer. Because Krovi is not code-signed yet, Windows SmartScreen may display “Windows protected your PC”; select More info and then Run anyway after verifying the checksum.
  4. Open Krovi with Ctrl + Alt + Space or click the pill at the top of your screen.

System requirements

Windows
Windows 10 or 11, 64-bit. Tested on Windows 11; Windows 10 is untested.
Processor
64-bit CPU. Local dictation and Talk to Agent need AVX2 (CPUs from 2013 onward).
Runtime
Microsoft Edge WebView2, included with Windows 11 or fetched from Microsoft during install.
Source build
Clone and compile yourself with Node and Rust: see build instructions in the docs.
