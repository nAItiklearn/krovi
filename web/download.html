Install in four steps

  1. Download the x64-setup.exe installer (the .msi is for managed deployments).
  2. Verify it. The hash must match the one above (or the digest GitHub shows beside the file).
    PowerShell
    Get-FileHash .\Krovi_0.1.0_x64-setup.exe -Algorithm SHA256
  3. Run it. If SmartScreen says “Windows protected your PC”, choose More info → Run anyway. Krovi isn’t code-signed yet.
  4. Summon it with Ctrl + Alt + Space, or click the pill.
WindowsWindows 11, 64-bit. Windows 10 is untested: Krovi has only been tested on Windows 11.
RuntimeMicrosoft Edge WebView2 (included with Windows 11). If it’s missing, the installer fetches it from Microsoft.
NetworkNot required. Weather and exchange rates are optional lookups; everything else works offline.

Why the SmartScreen warning? Windows is wary of installers from publishers it hasn’t seen before, and Krovi isn’t code-signed yet. That’s why we publish SHA-256 checksums and build in public: you can confirm the file is exactly what GitHub Actions produced.
