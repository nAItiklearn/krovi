What’s new in Krovi.

Every release, newest first. Krovi follows plain semantic versions and is built in the open, so each entry links to the source.

v0.2
“Island”
1 November 2026 · Released

The shelf moves to the top of your screen.

Krovi 0.2 turns the dropdown into a pill that lives at the top of your screen and springs open into the panel, then keeps everything on it live. It’s built on the clean-main branch; try it today in the browser demo.

New

  • The Island. A small pill at the top centre of your primary monitor that morphs into the 15-tool panel and back. It never moves when it grows, folds away with Esc, a click elsewhere or the hotkey, and an invisible-area click-through means it never blocks the app underneath.
  • Live clipboard. Copies appear within a fraction of a second, the pill glows, and entries from password managers are never stored.
  • Live now playing. Title, artist, artwork and a ticking progress bar read from the Windows media session, with play/pause, next and previous.
  • RAM and disk strip. Memory and system-drive usage refresh every two seconds along the bottom of the panel.
  • Local voice, from a closed command list. Dictate notes, and run a fixed set of spoken commands: open any tool, timers and Pomodoro (including pause and cancel), new note, media controls, put the selection on the shelf or send it to your phone, open a folder or launch an app from a closed set (Windows known folders, Quick Access, your Start menu), list what is in a folder, find a file by name in the Windows Search index, and set a reminder with the exact date and time read back. It is not open-ended chat: anything outside the list is ignored. Recognition runs on your PC with Windows speech (SAPI 5) and voice commands make zero network calls, shown by a socket capture in the audit. Every phrasing, and what is not supported, is in the docs.
  • Real reminders. A timed Calendar entry rings: a Windows notification and the system reminder sound at the set time, whether Krovi is a pill, a panel or hidden. Snooze 5 or 10 minutes, dismiss, or click to open the Calendar. Reminders missed while Krovi was closed fire once on the next start, marked as missed. With Windows Do Not Disturb on, the notification waits quietly in the notification centre (no banner, no sound) and the Calendar warns you.
  • Explain. Paste text for an on-device summary (short, medium or key points) and have it read aloud with a Windows voice. Optionally add your own ElevenLabs key to read aloud with ElevenLabs voices; that sends the text being read to api.elevenlabs.io, is off by default, and falls back to the Windows voice on failure. The key lives in Windows Credential Manager. There is no AI-written explanation in this version.
  • Holidays, offline. The Calendar bundles India (gazetted, restricted and observances, from the Department of Personnel and Training), US federal holidays (OPM) and Great Britain bank holidays for England and Wales, Scotland and Northern Ireland (GOV.UK), 2025 to 2027, with a documented source for each year.
  • Real checklists in Notes. Tick-box items sit inline between paragraphs of text in the same note.
  • Quick Transfer. Send files between this PC and your phone over your own Wi-Fi with a QR code, with an optional PIN. No cloud relay, no account; the local server exists only while a share is open and expires on its own. It is plain HTTP on your local network, so use a network you trust. If the phone can’t connect, allow Krovi on Private networks in the Windows firewall prompt; the troubleshooting notes explain the rest.
  • Six themes and an idle companion. Graphite, Porcelain, Mochi, Arcade, Terracotta and Tide, or follow Windows. After a few idle seconds the collapsed pill rests as a pair of eyes that wake the moment you touch it; it can be switched off.
  • A new look. Glass and blur surfaces, restrained type and spring motion, in the theme of your choice.
  • A real website and demo. This site, plus a live browser demo of the actual interface at /demo/.

Improved

  • Settings for the hotkey (with clear errors when it’s invalid or taken), showing the pill, collapse on blur, hiding in fullscreen, and launching at login.
  • A watchdog in the window shell, so expanding or folding can never leave Krovi stuck half-way.
  • Single instance: launching Krovi again expands the existing panel.

Privacy

  • Still zero telemetry. The outbound requests are optional keyless lookups (weather, a city-name search, exchange rates) and, only if you add your own key, ElevenLabs read-aloud, which sends the text being read. Voice makes none. Quick Transfer runs a server on your local network only while a share is open. The network audit covers each one.

v0.1.0
First public build
31 October 2026 · Released

The first installer.

The original left-rail panel, with the core tools and the privacy audit behind it.

What shipped

  • Windows installers (.exe and .msi), built by GitHub Actions from a tagged commit.
  • The panel with a left tool rail: clipboard history, paste stack, timers and stopwatch, Pomodoro, file shelf, media controls, weather, notes, world clocks, units and currency, calculator, command palette and screen time.
  • Keyless weather (Open-Meteo) and exchange rates (Frankfurter) as the only network calls, documented in a published network audit.
  • An automated test suite: 99 Rust tests and 26 frontend tests at release.
