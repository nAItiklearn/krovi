v0.3.0
Latest release

19 tools, Whisper dictation and optional AI keys

Adds four new tools, system-wide Whisper dictation, ten themes and optional bring-your-own AI keys stored in Windows Credential Manager. See the network audit for verification details.

Added in v0.3.0

  • 19 tools. Agent, Circle to Ask, Clean My OS and Extras join the 15 tools from v0.2. Extras bundles a launcher, snippets, file rules, workflows and local name search.
  • Agent Mode and Talk to Agent. Local step planner for typed commands or optional Ctrl + Alt + A Whisper speech. Safe steps run; unfamiliar URLs, reminders and email drafts require approval. Krovi never sends email.
  • Circle to Ask and Screen Awareness. Ctrl + Alt + C reads a selected screen area once on your PC without saving the image. Separate Screen Awareness sessions run 5 to 30 minutes with a persistent indicator.
  • Dictation into any app. Hold or toggle Ctrl + Alt + D to type spoken words at the cursor via local Whisper (Tiny, Base or Small models verified by SHA-256 on AVX2 CPUs).
  • Clean My OS. Scans temporary folders, caches, crash dumps and old installers, leaves files modified in the last 24 hours untouched, and sends confirmed selections to the Recycle Bin without administrator rights.
  • Themes and Settings. Four new themes (Obsidian, Linen, Voxel and Pixel Meadow, ten total), read-aloud voice preview, and Settings → AI for Anthropic, OpenAI, Google Gemini or Groq keys.
  • Core reliability. Background timer and Pomodoro alerts, SQLite persistence for File Shelf and World Clocks, idle-aware Screen Time, and section-by-section Explain summaries.

Changed

  • Inline math in Ctrl + K. The standalone Calculator view was replaced by arithmetic expressions inside Ctrl + K (+ - * /, parentheses, decimals and percent); unit and currency conversion remain in Convert.
  • Voice calculator launch. Saying “open calculator” launches Windows Calculator from the Start menu.

v0.2.0
1 November 2026

Top-of-screen pill, live clipboard and Quick Transfer

Moved the shelf into a top-centre pill that expands into the tool panel, added Quick Transfer over local Wi-Fi, offline holidays, checklists and the browser demo.

Added in v0.2.0

  • Top pill shell. Morphs into the panel and folds back on Esc, outside click or hotkey, with click-through around the pill and fullscreen auto-hide.
  • Live clipboard, media and system stats. Instant clipboard updates (skipping password-manager copies), Windows GSMTC media session controls, and a RAM/disk strip.
  • Local voice commands (SAPI 5). Closed phrase list for opening tools, timers, notes, media, folders and reminders with zero network calls (see supported phrases).
  • Ringing reminders and offline holidays. Calendar notifications with snooze, plus bundled 2025–2027 public holidays for India, the US and Great Britain.
  • Explain and Quick Transfer. On-device summaries with Windows read-aloud (optional ElevenLabs key), plus QR file sharing over local Wi-Fi (troubleshooting notes).
  • Six themes and idle eyes. Graphite, Porcelain, Mochi, Arcade, Terracotta and Tide, with optional idle eyes in the closed pill.
