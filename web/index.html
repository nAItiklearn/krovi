Everything you reach for, in one pill.

Krovi is a free, open-source shelf for Windows that lives at the top of your screen as a small pill, then springs open into fifteen tools: live clipboard, timers, reminders that ring, notes with real checklists that you can dictate, a calendar with India, US and UK holidays, a lane to your phone over your own Wi-Fi, an on-device text summariser, and more. One hotkey. No account. Zero telemetry.

Clipboard & paste stack

Two clipboards for two kinds of work.

History quietly remembers everything you copied. The paste stack is the opposite: a deliberate, numbered workbench of nine slots that you push to and pop from, last in, first out. Fill a form, template a reply, shuttle a dozen values between apps.

  • Nine numbered slots, slot 1 on top. Past nine, the oldest drops off
  • You decide what goes in. It never fills itself
  • Kept apart from history, so neither clutters the other
  • Pinned history items are never evicted

    Calendar

    A calendar that rings, and knows the holidays.

    A clean month view where a timed entry is a real reminder: at that minute Krovi raises a Windows notification, whether it is a pill, an open panel or hidden. Beside it sits a bundled, offline holiday dataset. Nothing to sync, no account, no network call.

    • Rings on time. A Windows toast and the system reminder sound at the set time, in the pill, panel or hidden
    • Snooze or dismiss. Snooze 5 or 10 minutes; clicking the notification opens the Calendar
    • Closed at the time? It fires once when Krovi next starts, marked as missed
    • Do Not Disturb is respected. With it on, Windows files the toast quietly in the notification centre and Krovi warns you in the Calendar. A banner lasts about five seconds
    • Holidays for India (Department of Personnel and Training), the US (OPM) and Great Britain (GOV.UK), 2025 to 2027, each year with a documented source

      Quick Transfer

      New in v0.2LAN onlyQR codeAuto-expiresOptional PIN

      Drop a file and a QR code appears. Scan it and the file downloads to your phone over your own Wi-Fi; the same page can send a file back. There is no cloud relay and no account, and the small local server exists only while a share is open, then closes itself. It is plain HTTP on your local network, so use a network you trust. If the phone can’t connect, allow Krovi on Private networks in the Windows firewall prompt.

      Explain

      New in v0.2On-device summaryRead aloudOptional ElevenLabs

      Paste any text and get a summary (short, medium or key points), made on your PC with no network call. It is extractive: it picks out the important sentences rather than writing new ones, and Krovi does not generate AI explanations in this version. Then have the text read aloud with a built-in Windows voice. If you add your own ElevenLabs key, read aloud can use ElevenLabs voices instead; that sends the text to ElevenLabs, is off until you set it up, and falls back to the Windows voice if it fails. The key is kept in Windows Credential Manager.

      Voice

      Say it. Krovi does it.

      Dictate a note or run a command with your voice, recognised entirely on your PC by Windows’ own speech engine. No cloud speech service, no upload, no account.

      • A closed set of commands, not a chat. Krovi listens for a fixed list of phrasings and does nothing with anything else. It never interprets, guesses at or sends off what you said. The free-speech parts are only the body of a note, the text of a reminder and a file search term.
      • Dictate notes. Press the mic in Notes and speak; the words land as a note.
      • Run commands. Open a tool, start a timer or Pomodoro, make a note, set a reminder with an exact time read back, open a folder, launch an app from your Start menu, list what’s in a folder, or find a file by name in the Windows Search index.
      • Local by design. Recognition runs on-device with Windows speech (SAPI 5). Voice commands make zero network calls, checked with a socket capture in the network audit. Nothing is kept except what a command creates.
      • Push to talk. It listens only after you start it: no wake word, nothing in the background.
      • In v0.2: “this”. Say “put this on the shelf” or “send this to my phone” and Krovi uses what you had selected when you started the command, read only then.
      • Open a tool“open the calendar”
      • Set a reminder“set a reminder for tomorrow at nine to renew the passport”
      • Open a folder“open downloads”
      • Launch an app“launch notepad”
      • Find a file“search for tax return”
      • List a folder“what’s in downloads”

      Privacy

      Zero telemetry. Not a promise, a ledger.

      Most apps ask you to trust them. Krovi shows its work: every outbound request the app can make is listed below, the source is public, and an audit traces each one to the line of code that sends it.

      krovi — outbound requests
      # Every network request Krovi can make. That is the whole list.
      weather GET api.open-meteo.com/v1/forecastcoarse lat/long (about 11 km). Only when you open or refresh Weather.
      city search GET geocoding-api.open-meteo.com/v1/searchthe city name you type, only if Windows Location is unavailable and you search for one.
      currency GET api.frankfurter.dev/v1/latestthe base currency code only. Only when you refresh exchange rates.
      read aloud (opt-in) api.elevenlabs.iooff by default, and only if you paste your own ElevenLabs key in Explain. Then the text you ask it to read aloud is sent to ElevenLabs. Windows voices stay on-device and are the default (in v0.2).
      quick transfer LAN only, while a share is opena short-lived local server for your own Wi-Fi (in v0.2). No relay, no outbound request.
      voice nonedictation and every voice command make zero network calls. Evidence: a socket capture in the audit’s “Voice v3” section.
      everything else
      # telemetry, analytics, crash reports, ads, accounts, auto-update:
      none

        FAQ

        Questions, answered.

        Is Krovi really free?

        Yes. It’s MIT-licensed free software with no trial, key, paywall or paid tier. Every feature is available to everyone.

        Does Krovi send my data anywhere?

        No. Clipboard, notes, files, reminders and screen time stay on your PC. The only outbound requests are the optional weather and exchange-rate lookups, and read-aloud through ElevenLabs if you add your own key (it is off by default and sends the text being read). All are listed in the privacy ledger. Weather sends a coarse location, rates send a currency code, and nothing else leaves.

        How private is voice?

        Speech is recognised on your PC by Windows’ own recogniser. There is no cloud speech service and no audio upload, and voice commands make zero network calls (the audit includes a socket capture). Voice starts when you press the mic, so nothing is listening in the background. Commands are a closed list of phrasings, not open-ended chat; the docs list them all and what is not supported.

        Which versions of Windows are supported?

        Windows 11, 64-bit. Windows 10 is untested: it may work, but we have only tested on Windows 11 and won’t claim more. Krovi is Windows-first, because it reads the Windows media session and uses Windows window and tray features. There is no macOS or Linux build.

        Will the pill get in the way of my work?

        It shouldn’t. Clicks anywhere outside the visible pill or panel pass straight through to the app underneath, the pill hides itself during fullscreen games, video and presentations, and it folds away when you click elsewhere. All three are optional in Settings.

        Can I change the hotkey?

        Yes. The default is Ctrl + Alt + Space; rebind it in Settings. If the combination is invalid or taken, Krovi tells you instead of silently failing.

        Why does Windows SmartScreen warn about the installer?

        Krovi isn’t code-signed yet, and SmartScreen is cautious about unsigned installers from new publishers. Verify the SHA-256 shown on the download page, then choose More info → Run anyway. The installer is built by public GitHub Actions workflows from the public source.

        How do I quit or uninstall it?

        Quit from the tray menu, the panel header, or Ctrl + Q. To uninstall, use Settings → Apps in Windows. Steps are in the docs.

        How does it compare to paid alternatives?

        Krovi’s edge is being free, open source and verifiably private. The comparison page is honest: where we can’t confirm a competitor’s feature from public information we say “Not verified”, and we list where more mature apps are still ahead.

        Can I contribute?

        Please. Issues, ideas and pull requests are welcome on GitHub. Keep changes local-first and privacy-preserving, and add tests.
