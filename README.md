# Krovi

**website** https://www.krovi.tech/

A small partner which dont let u feel alone , by living top of your screen 

## what is it?

Krovi is a free, offline , open source windows app which has around 19 tools in one place like notes , cleanmyOS(it works really well), timers , circle to ask(still working on it), open apps by commands . 

## how does it works?
it runs in baground , can be opened , close using keyboard shortcuts . 
most of the features are locally on your pc except ai ones

## Run Locally

do install these before-
* node.js and npm
* rust
* 64 bit MSVC  c++ build tools 
* web 2 view2 runtime

1. clone the repo
```
git clone https://github.com/nAItiklearn/krovi.git
cd krovi
```
2. install dependencies 
```
npm install
```
3. run the browser version
```
npm run dev
```
